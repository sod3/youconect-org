## Remaining work before institutional launch

1. Configure and test external PostgreSQL, HTTPS hosting, SMTP, encrypted persistent/shared storage, backup retention, monitoring, and production secrets. Disable demo access.
2. Finish the specific membership, invitation, community/channel, event and application management gaps above.
3. Implement storage/provider adapters and queued notifications if required by launch scope; enforce all commercial entitlements consistently.
4. Complete an independent security/accessibility review and institution-specific privacy, safeguarding, verification-evidence, retention and legal policies.
5. Add production load tests, real-user performance measurement, multi-instance socket/queue infrastructure when justified, and restore drills.

The application is usable locally with real persistence and permissions. It should not be described as a fully finished, production-certified implementation of every feature in the brief.
